# MA-CLI Branding & Animation Specification

## Product identity
MA-CLI = Multi-Agent CLI. The symbol combines an abstract M/A monogram with a terminal prompt motif.

## Motion system
- Idle: 6–8 second orbital loop.
- Thinking: continuous orbit + 2 second pulse.
- Executing: orbit + progress sweep.
- Success/failure: keep the brand static; communicate status with separate UI indicators.

## Integration
Splash: use ma-cli-animated.svg.
App icon: use ma-cli-symbol.svg.
Terminal/TUI: use ma-cli-terminal.svg.
Documentation: use ma-cli-wordmark.svg.
Dark/print fallback: use ma-cli-mono.svg.

Do not present the animation as an Anthropic/Claude imitation. It is MA-CLI's independent identity.
